# Family Recipes

A static, interactive family recipe collection designed for GitHub Pages.

## Publish with GitHub Pages

Recommended repository name: `family-recipes`

1. Create a new GitHub repository.
2. Upload the **contents of this folder** to the repository root. `index.html` should be at the top level of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub finishes publishing, the site should be available at a URL like:
   `https://YOUR-USERNAME.github.io/family-recipes/`

The `.nojekyll` file tells GitHub Pages to serve the files as a plain static site.

## Structure

- `index.html` — recipe collection homepage
- `recipes/` — interactive recipe pages
- `assets/` — shared JavaScript and CSS
- `sources/` — original family recipe scans/PDFs
- `favicon.svg` — site favicon

## Privacy

Publishing this repository with GitHub Pages makes the website and the files it links to publicly accessible. The `sources/` directory contains original family recipe scans.
