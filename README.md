# Family Recipes

Interactive family recipe collection published as a static GitHub Pages site.

## Site

This repository contains 15 interactive family recipes with:

- batch scaling
- ingredient and method checklists
- quick variation presets
- dynamic substitutions and add-ins
- print-friendly recipe layouts
- search and category filters

The original/source recipe remains the default on every page. Family/source variations are labeled separately from creative adaptations.

## GitHub Pages

Publish from the `main` branch at `/ (root)` under **Settings → Pages**.

Expected site URL:

`https://vsxd409.github.io/family-recipes/`

## Original scans

The original recipe scans remain in the family archive and are not currently stored in this public repository.
